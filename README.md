Factify 
This is a simple web-based quiz application built with .NET 8 MVC. You can make a new quiz, edit it and delete it. Its also possible to take the quiz. When you are done you get a score, and can try again or go back to the main menu. 

How to start the project:

dotnet restore
dotnet ef database update
dotnet build

Use this if ur not standing in the folder with the project 
dotnet run --project Factify.csproj

This if the project is in the folder
dotnet run 

or alternative use 
f5.
